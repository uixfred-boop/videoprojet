# Motion style reference

`motion-style-reference.mp4`: 1280x720, 30 fps, 24 s, sent by the user as
the reference for all motion text. Measured from the video:

- **Colors:** background `#0A0A0A`, text `#FFFFFF`, words not yet said
  `#535353`, inverted cards `#FFFFFF` background with `#282828` text, fading in
  from about `#C8C8C8`.
- **Size:** cap height about 11.4% of frame height, centered, single line.
- **Punch-in:** first frame at about 165% scale, then 124%, 110% and 100% by
  frame 5. That is an exponential settle with about 1 frame time constant.
- **Rhythm:** music around 155 BPM. Shots change every 0.4 to 0.8 s, then
  every 0.2 s in the final run ("Dream / big / and / work / hard / you / can").
- **Inverted cards** (7 of about 50 shots): typography, promos, perfect,
  ready?, important, yeah!, short. Each is the key word of its sentence.
- **promos:** letter spacing opens about 17% over 0.4 s, then a wipe out.
- **typography / important / yeah! / short:** the end of the word starts
  leaning (italic) and straightens within about 0.2 s.
- **Simple and powerful / combined with rhythm:** whole phrase on screen in
  gray, the word being said in white.
- **it’s / getting / hot / maybe / faster... / Are you:** letters turn from
  gray to white, left to right.
- **rhythmic / black and white / animation:** exit by speeding off to the
  right while dimming, right before a cut.
- The original uses a bold sans serif. This project replaces it with
  Grandstander Medium.
