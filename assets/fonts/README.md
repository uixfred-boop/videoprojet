## Saans (not included — add your licensed files)

Saans is a commercial typeface by Displaay Type Foundry (https://displaay.com).
It is not bundled because its license does not allow redistribution.
Once you have a license, put the web fonts here with these exact names:

- `Saans-Regular.woff2` (400)
- `Saans-Medium.woff2` (500)
- `Saans-SemiBold.woff2` (600)
- `Saans-Bold.woff2` (700)

The site picks them up automatically. Until then it falls back to Inter Tight.
